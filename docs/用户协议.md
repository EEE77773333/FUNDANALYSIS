## 二、服务性质与定位（重要）

2.1 本服务是**面向个人学习与研究的数据分析工具**，提供基金/指数/宏观数据的聚合展示，以及在用户自行配置的大模型（LLM）支持下生成的分析文本。

2.2 **本服务不构成、也不应被理解为任何形式的投资建议、投资咨询、荐股荐基、收益承诺或代客理财。** 所有输出内容均为基于历史数据的机械计算结果或算法生成的参考信息，不针对任何特定投资者的财务状况、风险承受能力与投资目标作出。

2.4 基金/证券投资存在本金损失风险，历史业绩不代表未来表现。请在具备相应风险识别与承受能力的前提下，独立判断并咨询持牌专业人士。

## 四、用户自带密钥（BYOK）与自带数据源

4.1 本服务采用 **BYOK（Bring Your Own Key）** 模式：AI 分析能力所使用的模型由你**自行配置**。你可以填入任意兼容 OpenAI 协议的服务（含 DeepSeek、通义千问、智谱、Kimi、OpenAI、硅基流动、OpenRouter 等），也可以指向你自己部署的本地模型（如 Ollama、vLLM、LM Studio）。

4.2 你需要自行承担所配置模型的**全部费用**（含 token 消耗、超出免费额度产生的费用）。我们对第三方模型的可用性、输出质量、计费规则与政策变更**不作任何保证**。

4.3 **你填入的密钥将被发送并调用你所选定的第三方服务。** 请自行确认该第三方服务条款、数据处理政策与合规性，并**仅使用你有权使用的密钥**。不得填入他人密钥或通过非授权手段获取的密钥。

4.4 密钥的存储方式、可见范围与安全级别，详见《隐私政策》第三章、第五章。

4.5 行情数据源同理由你自行选择（东方财富公开接口、AKShare、Baostock、Tushare 等）。Tushare 等需 token 的数据源，其 token 与使用规范由你自行负责。
