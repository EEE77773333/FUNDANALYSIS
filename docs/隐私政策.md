## 一、引言与适用范围

1.1 我们深知个人信息对你的重要性，并将尽力保护其安全可靠。本政策说明我们在你使用「基金智能分析系统」托管版时**收集哪些信息、为何收集、如何存储与共享、以及你享有的权利**。

1.2 **本政策仅适用于托管版（我们运营的线上服务）。** 如果你通过开源代码自部署运行本项目，**所有数据均留存于你自己的服务器或电脑，我们不接收、不接触、不采集任何信息**——此时本政策不适用，你就是自己数据的唯一控制者。

1.3 使用本服务前，请仔细阅读并充分理解本政策。注册时勾选同意即表示你已理解并接受。

## 二、我们收集哪些信息

我们遵循**最小必要**原则，仅收集为提供服务所必需的信息：

### 2.1 你主动提供的信息
| 类别 | 具体内容 | 用途 |
| --- | --- | --- |
| 账号信息 | 邮箱、昵称、密码（**仅存储加盐哈希，不存明文**） | 注册、登录、身份识别 |
| 集成配置 | 你填入的 LLM 密钥、模型名、接口地址；数据源类型与 token | 代你调用你选定的第三方服务 |
| 你输入的业务内容 | 你提交的分析对象、问题、组合持仓等 | 执行分析、生成结果、保存历史记录 |

### 2.2 使用服务时自动产生的信息
| 类别 | 具体内容 | 用途 |
| --- | --- | --- |
| 配额计量 | 调用次数、消耗的模型与 token 估算量、时间戳 | 计量配额、防止滥用、成本核算 |
| 登录凭证 | 会话 token（见第六章） | 维持登录状态 |
| 基础日志 | 请求时间、接口名、错误码、脱敏后的 IP | 故障排查、安全防护 |

### 2.3 我们**不**收集的信息
- 我们**不**接入通信录、短信、相册、麦克风、摄像头、地理位置；
- 我们**不**收集你的银行账户、支付卡号（支付由第三方支付机构处理）；
- 我们**不**为广告投放目的进行跨站追踪，**不**出售你的个人信息。

## 三、信息如何存储

3.1 **存储位置**：托管版数据存储于我们位于**中华人民共和国境内**的服务器数据库中（生产环境使用 PostgreSQL，单机/开发环境使用 SQLite）。

3.2 **密钥存储的重要说明**：你配置的 LLM 密钥与数据源 token 以**明文 JSON** 形式存储于用户配置表（`user_integrations`），其安全级别**等同于数据库本身的安全级别**。界面上一律只回显**掩码**（如 `sk-abcd****wxyz`），不会回传明文给前端。我们建议你：
- 使用**可随时吊销、设置了额度上限**的密钥，不要使用主账号的全权限密钥；
- 定期轮换密钥；
- 如密钥泄露，立即在对应厂商后台吊销。

3.3 **行情数据缓存**：为降低对第三方接口的压力并提升响应速度，我们会缓存公开行情数据（带 TTL 过期时间），缓存内容**不含你的个人信息**。

3.4 **保留期限**：账号信息与配置在账号存续期间保留；注销后我们在合理期限内删除或匿名化。配额计量日志与安全日志按法规要求至少保留 6 个月。

## 四、信息如何被共享与委托处理

我们**不出售**你的个人信息。仅在下列必要情形下共享：

4.1 **调用你配置的大模型服务（关键）**：当你使用 AI 分析功能时，**你的提问内容、被分析对象的相关数据，以及你配置的密钥，会通过互联网发送至你自行选定的第三方大模型服务商**（如 DeepSeek、阿里云通义、智谱、月之暗面、OpenAI、硅基流动、OpenRouter，或你自建的本地模型）。
- 该等信息的处理受**该服务商**的隐私政策与服务条款约束，请在配置前自行查阅；
- 我们**无法控制**第三方对数据的处理方式，也**不为其行为承担责任**；
- 若你指向**本地部署模型**（如 Ollama），则内容不离开你的网络环境。

4.2 **行情数据源**：分析所需的数据会向公开行情接口发起请求。该过程通常**不包含**你的个人信息（部分需 token 的源会携带你配置的 token）。

4.3 **支付与基础设施**：支付由第三方支付机构处理；服务器、数据库、对象存储由云服务商提供。我们仅向服务商提供**必要的最小信息**，并要求其履行保密与安全义务。

4.4 **法律要求**：依据法律法规、监管指令、司法或行政机关的强制要求，我们可能披露必要信息。我们将在法律允许范围内告知你。

在法律法规允许的范围内，你有权：

| 权利 | 如何行使 |
| --- | --- |
| **查阅 / 复制** | 在"账户设置"查看账号与配置信息；可要求我们提供副本 |

## 六、Cookie、会话与本地存储

6.1 托管版使用 **会话 token** 维持登录状态。token 存储于浏览器会话与页面地址参数中，注销或过期后失效。

6.2 我们**不**使用第三方广告或跨站追踪 Cookie。用于统计服务运行状况的技术性标识，不用于识别个人身份。

6.3 自部署版**不使用**上述机制，登录状态由你本地环境管理。

---

## 七、信息安全

7.1 我们采取如下措施保护信息安全：
- 密码加盐哈希存储，不保存明文；
- 敏感配置在界面回显时一律掩码；
- 传输层使用 HTTPS 加密；
- 数据库访问遵循最小权限原则，运维操作留痕；
- 定期备份与安全巡检。

7.2 **已知局限（如实告知）**：密钥以明文存于数据库，依赖数据库与服务器的整体安全。多租户大规模生产环境建议自建时改用 **KMS / 密钥托管服务**并开启**数据库加密**。若发生安全事件，我们将按法律要求及时告知受影响用户并向监管部门报告。

7.3 互联网环境并非绝对安全。请务必设置**强密码**、不与他人共享账号，并使用独立的、可限额的 API 密钥。

## 八、未成年人保护

8.1 本服务面向具备完全民事行为能力的成年人。**我们不面向未满 18 周岁的未成年人提供服务**，也不会主动收集其个人信息。

8.2 如你是未成年人，请在监护人陪同与同意下使用；如我们发现误收集了未成年人信息，将及时删除。

8.3 鉴于本服务涉及投资数据分析，**未成年人不应使用其作出任何投资决策**。

## 九、信息出境

9.1 若你选择的大模型服务商**位于境外**（如 OpenAI、Anthropic 等），使用相关功能将导致你的数据**跨境传输至境外**。请在你自行判断合规性后选择；我们不对该跨境传输的合法性承担责任。

9.2 如你需避免数据出境，请选择**境内服务商**或**本地部署模型**。

10.1 我们可能因功能变化或法规要求更新本政策。更新后将修改版本号与生效日期并公示；**重大变更**（如新增收集项、扩大共享范围）将以站内公告或邮件方式提前通知。

10.2 若你不同意更新后的政策，应停止使用并注销账号；继续使用即视为接受。

## 十一、自部署用户的特别说明

11.1 本项目开源（AGPL-3.0），你可以完全离线自部署。**在此模式下，本政策基本不适用**：账号、密钥、分析记录均只存在你的数据库中，我们不接收任何数据。

11.2 但请注意：即使自部署，**当你调用云端大模型或云端行情接口时，相关数据仍会发送给对应服务商**，仍受其政策约束。彻底避免数据外发的方式是：使用本地模型（Ollama / vLLM）+ 本地或公开免鉴权行情源。
